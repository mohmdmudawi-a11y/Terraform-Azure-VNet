# Terraform Azure Virtual Network

## Overview

This project demonstrates deploying Azure networking resources using Terraform Infrastructure as Code.

## Resources Created

- Azure Resource Group
- Azure Virtual Network
- Azure Subnet
- Network Security Group

## Technologies

- Microsoft Azure
- Terraform
- Infrastructure as Code

## Deployment Steps

Initialize Terraform:

```bash
terraform init
```

Validate configuration:

```bash
terraform validate
```

Create deployment plan:

```bash
terraform plan
```

Deploy resources:

```bash
terraform apply
```

Remove resources:

```bash
terraform destroy
```
